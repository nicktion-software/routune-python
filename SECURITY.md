# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, discussions or pull requests.

Report them privately through GitHub's [private vulnerability reporting](../../security/advisories/new) for this repository, or by email to **security@routune.com**. Include:

- a description of the issue and its impact,
- the library version and runtime you used,
- steps to reproduce, or a proof of concept.

We acknowledge reports within two business days and keep you informed until the issue is resolved. Please give us a reasonable time to release a fix before you disclose the issue publicly.

## Supported versions

Security fixes are released for the latest minor version of this library.

## If an API key was exposed

Revoke it immediately in Routune under **Settings → API keys**, then create a new one. Revoking takes effect on the next request.
